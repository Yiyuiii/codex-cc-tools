## Scope

This stable release promotes `0.2.0-beta.0` after Codex-side validation. The
release keeps the focused two-tool public surface:

- `cc_review`
- `cc_delegate`

`cc_delegate` is the autonomous Claude Code execution bridge. It accepts one
complete `prompt` plus optional process/model settings, runs Claude Code in
non-interactive `bypassPermissions` mode, and returns structured output to
Codex. Execution-space, branch, container, path, and command policy remain
outside this MCP tool.
