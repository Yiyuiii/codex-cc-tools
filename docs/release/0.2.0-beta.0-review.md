# 0.2.0-beta.0 Release Review

Status: prepared for npm `next` prerelease through GitHub Actions Trusted
Publishing.

Checked on: 2026-05-22

## Scope

This beta intentionally changes the public tool surface after `0.1.0`:

- removes the public `cc_research` and `cc_verify` MCP tools and matching CLI
  commands;
- keeps `cc_review` as the read-only critique path;
- turns `cc_delegate` into the autonomous execution path that accepts one
  complete `prompt` plus optional process/model settings;
- removes `delegate` fields for `context`, `acceptanceCriteria`, execution
  isolation, path policy, and command policy;
- documents that execution space and command policy are external caller
  responsibilities;
- runs `cc_delegate` through Claude Code `bypassPermissions` for non-interactive
  autonomous execution.
