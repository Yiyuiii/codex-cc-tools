# 0.3.0-beta.1 Release Review

Status: prepared for npm `next` prerelease through GitHub Actions Trusted
Publishing.

Checked on: 2026-05-29

## Scope

This prerelease narrows Ark Coding Plan review defaults:

- `cc_review` with `providerProfile: "ark_coding_plan"` no longer passes
  Claude Code `--allowedTools default` unless the caller explicitly provides
  `tools`;
- non-Ark `cc_review` defaults are unchanged and still use `tools: ["default"]`;
- explicit Ark tools requests are preserved, including `tools: "default"`;
- regression tests cover both the default omission and explicit preservation
  behavior.
