# 0.3.0-beta.0 Release Review

Status: prepared for npm `next` prerelease through GitHub Actions Trusted
Publishing.

Checked on: 2026-05-28

## Scope

This prerelease expands provider support and includes the package maturity work
prepared after `0.2.1-beta.1`:

- adds the explicit `ark_coding_plan` provider profile for Volcengine Ark
  Coding Plan;
- routes Ark Coding Plan through the Anthropic-compatible Claude Code endpoint
  `https://ark.cn-beijing.volces.com/api/coding`;
- reads Ark credentials from `ARK_API_KEY`, falling back to
  `VOLCENGINE_API_KEY`, and keeps provider tokens scoped to the Claude Code
  child process;
- maps common Claude Code aliases (`opus`, `sonnet`, `haiku`) and
  `Doubao-Seed-2.0-pro` to `doubao-seed-2.0-pro` for the Ark profile;
- extends `doctor`, CLI help, provider schemas, tests, README files, docs, and
  examples for the new provider profile;
- includes the install/uninstall CLI, actionable doctor diagnostics, public
  maturity docs, and package-surface updates prepared after `0.2.1-beta.1`.
