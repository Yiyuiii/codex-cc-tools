# 0.4.0-beta.2 Release Review

Status: prepared for npm `next` prerelease through GitHub Actions Trusted
Publishing.

Checked on: 2026-06-19

## Scope

This prerelease adds and validates the Ark Agent Plan route and the current Ark
Coding Plan model default:

- adds explicit `ark_agent_plan` provider profile for the separate
  `OPENAI_API_KEY_DOUBAO` plan/quota pool;
- routes Ark Agent Plan Claude Code subprocesses through
  `https://ark.cn-beijing.volces.com/api/plan`;
- maps Ark Agent Plan common Claude Code aliases to `glm-5.2`;
- routes Ark Coding Plan common aliases to `ark-code-latest` while keeping old
  `glm-latest` and Doubao model names as compatibility aliases;
- treats Ark common aliases case-insensitively;
- formats Claude Code `structured_output` when `result` / transcript are blank;
- updates README, Chinese README, installation, security, troubleshooting,
  tool-contract, Codex usage, examples, AGENTS memory, and changelogs.
