## Release Notes

- `release:smoke` intentionally runs `npm run build` first to avoid checking stale `dist/` artifacts.
- `cc_verify` is command-exec, not read-only. Its MCP annotations are expected to be `readOnlyHint=false` and `destructiveHint=false`.
- `src/version.ts` must be updated with `package.json` when the package version changes. `tests/release-assurance.test.ts` fails if they diverge.
- A POSIX tarball install smoke remains recommended before a public publish because this Windows environment cannot verify executable-bit behavior after npm bin install.
