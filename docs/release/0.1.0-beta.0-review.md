## Release Channel

The release workflow publishes tags with prerelease suffixes to npm `next` from branch `next`. The intended tag is:

```bash
v0.1.0-beta.0
```

Stable tags publish to npm `latest` from `main` and require `.release-validation/v<version>.md`.

## Known External Gate

This Windows environment is authenticated to GitHub but not to npm. GitHub Actions can publish through OIDC only after npm trusts `Yiyuiii/codex-cc-tools` and workflow file `release.yml`. If npm trust has not been configured for this new package, the GitHub release workflow will fail at the publish authentication step and should be rerun after configuring the trusted publisher.
