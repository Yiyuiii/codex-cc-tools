## Scope

This prerelease refines the `cc_delegate` MCP description after maintainer
feedback:

- removes wording that could be read as a tool-level restriction on parallel
  calls;
- describes the actual mechanism instead: one call starts one DeepSeek-default
  Claude Code subprocess, receives one complete prompt plus optional process
  settings, and returns structured results;
- documents that parallelism comes from launching multiple independent
  `cc_delegate` calls.
