# 0.3.0-beta.2 Release Review

Status: prepared for npm `next` prerelease through GitHub Actions Trusted
Publishing.

Checked on: 2026-05-29

## Scope

This prerelease updates review tool defaults and native Anthropic Opus routing:

- `cc_review` no longer injects default `tools: ["default"]` for any provider
  profile;
- omitted or empty `tools` now means no Claude Code `--allowedTools` flag is
  passed;
- explicit `tools` requests are still preserved as the caller-specified
  allowlist;
- review packet guidance uses generic repository-tool wording when no review
  tools are set;
- native Anthropic `model: "opus"` resolves to `claude-opus-4-8`, because local
  smoke showed Claude Code's own `opus` alias still resolving to
  `claude-opus-4-7`;
- `effort: "max"` remains supported and was smoke-tested against
  `claude-opus-4-8`.
