# 0.4.0-beta.0 Release Review

Status: prepared for npm `next` prerelease through GitHub Actions Trusted
Publishing.

Checked on: 2026-06-04

## Scope

This prerelease adds the experimental direct Gemini review provider:

- adds `providerProfile: "gemini"` to the provider registry and schemas;
- maps common aliases (`opus`, `sonnet`, `haiku`) and
  `models/gemini-3.5-flash` to `gemini-3.5-flash`;
- implements a direct `cc_review` backend that calls Google Gemini
  `generateContent` without launching Claude Code;
- reads Gemini credentials from `GEMINI_API_KEY`, then `GOOGLE_API_KEY`, then
  `GOOGLE_GENERATIVE_AI_API_KEY`;
- sends Gemini credentials through the `x-goog-api-key` header, not the URL;
- supports `HTTPS_PROXY` / `HTTP_PROXY` for direct Gemini transport;
- uses `maxOutputTokens: 8192`, a 60 second direct request timeout, and clear
  failures for empty successful responses;
- reports that Claude Code `tools`, `effort`, and `cacheTtl` semantics do not
  apply to direct Gemini review;
- rejects `providerProfile: "gemini"` in `cc_delegate` because Gemini direct
  API does not expose Claude Code filesystem, shell, or edit tools;
- updates doctor, CLI/MCP descriptions, docs, examples, AGENTS memory, and
  changelogs.

  incorrectly inferred that `docs/architecture.md` was corrupted from a
