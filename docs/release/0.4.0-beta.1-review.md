# 0.4.0-beta.1 Release Review

Status: prepared for npm `next` prerelease through GitHub Actions Trusted
Publishing.

Checked on: 2026-06-04

## Scope

This prerelease refines the experimental direct Gemini review provider:

- adds optional `geminiProxyUrl` to `cc_review`;
- adds CLI option `--gemini-proxy-url`;
- resolves Gemini transport proxy as `geminiProxyUrl`, then inherited
  `HTTPS_PROXY`, then inherited `HTTP_PROXY`;
- keeps the proxy setting scoped to direct Gemini review so Claude Code-backed
  providers remain unaffected;
- updates README, Chinese README, installation, security, troubleshooting,
  tool-contract, Codex usage, examples, AGENTS memory, and changelogs.
