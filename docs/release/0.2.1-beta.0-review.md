Checked on: 2026-05-22

## Scope

This prerelease updates the `cc_delegate` contract for Codex-facing use:

- defaults `cc_delegate` to `providerProfile: "deepseek"`;
- updates the MCP tool description to present `cc_delegate` as a DeepSeek-default
  delegated worker for independent read-only or disjoint writable subtasks;
- documents that multiple independent `cc_delegate` calls may run in parallel;
- clarifies that destructive MCP metadata reflects capability, while prompts can
  still request read-only investigation;
- records the maintainer intent in `AGENTS.md` so future sessions treat
  `cc_delegate` as a low-cost worker rather than a rare high-risk-only tool.
